DreamWeave has three sides, and they are distinct engineering lanes:

- **Rust ecosystem:** OpenMW-facing Rust tools, reusable asset/configuration libraries and
  the L3i runtime. StroggForge is its build and release supply line.
- **Lua(u) / OpenMW:** mod content, OpenMW Lua tooling and the Cod3x field manual, all in St4sh.
  Documented here; not part of the Rust ecosystem.
- **Web and documentation sites:** the Mod Template docs shell and dreamweave-web.

Sharing an organization is not a dependency. Start with the [overview](@/ecosystem/overview.md),
follow the [map](@/ecosystem/map.md), choose a component from the
[project directory](@/ecosystem/projects/_index.md), or check the
[organization census](@/ecosystem/census.md) for every repository and whether it is still maintained.
Retired names have their own [historical lane](@/archaeology/history.md).
