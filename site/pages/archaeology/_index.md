Historical material explains why the current system exists. It never establishes a current
build target, active partnership or dependency, and it never appears in the current maps.

- [History and migrations](@/archaeology/history.md): superseded components, archived
  repositories, retired build environments and sites, each with its successor or an explicit
  statement that none has been reviewed.
- [Retired infrastructure](@/archaeology/retired/_index.md): one page per retired repository,
  organization, build environment and site, each marked **no longer maintained or supported**.
- [Organization census](@/ecosystem/census.md): every GitHub repository, and which are retired.
- [Infrastructure change log](@/releases/changes.md): dated migrations and the commits carrying them.
- [Maintainer notebooks](@/archaeology/notebooks.md): the hand-written root documents, sorted
  into current reference and history.

Follow the current contracts and platform matrix for operational work. Revisit history when
investigating a migration; do not copy old defaults into a new consumer unchanged.
